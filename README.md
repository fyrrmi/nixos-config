# nixos-config

personal nixos configuration, built from scratch as a learning project.

## environment

- kde plasma 6 on wayland
- sddm display manager
- pipewire for audio

## approach

classic configuration in a single `configuration.nix` file.
no flakes, no home-manager, no custom modules **yet.**

## structure
.
├── configuration.nix          # main config, versioned
├── hardware-configuration.nix # generated by nixos
└── README.md

these files mirror `/etc/nixos/`. the repo exists for version control and documentation
