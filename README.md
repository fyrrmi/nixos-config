# nixos-config

personal nixos configuration currently used on a thinkpad x1 carbon gen 12.

## approach

classic configuration, single `configuration.nix` file. no flakes, no home-manager, no custom modules, yet.

## structure

```
.
├── configuration.nix          # main config, versioned
├── hardware-configuration.nix # generated by the installer, never edited
└── README.md
```

these files mirror `/etc/nixos/`. the repo is not the system: the system lives in `/etc/nixos/`. the repo exists for version control and documentation.
